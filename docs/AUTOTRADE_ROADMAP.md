# Auto Trade Roadmap

## Phase 1 - Signal Bot MVP

- Telegram bot product commands and menu
- Monitor worker for smart-wallet signal polling
- Discovery worker foundation for periodic candidate processing
- User watchlist and alpha review queue

## Phase 2 - Wallet Layer

- wallet creation
- encrypted key storage
- deposit address
- balance
- withdraw
- private key export
- admin-only founder mode first

## Phase 3 - Strategy Layer

- strategy creation
- filters
- risk limits
- per-chain settings
- signal requirements

## Phase 4 - Execution Layer

- token buy execution
- swap routing
- slippage
- gas limits
- duplicate buy guard
- max exposure

## Phase 5 - Position Management

- open positions
- TP/SL
- trailing stop
- time-based exit
- emergency close
- PnL

## Phase 6 - Advanced Alpha Engine

- wallet performance decay
- smart-wallet reputation update
- auto promotion/demotion
- narrative clustering
- multi-wallet consensus
- false-positive suppression

## Security Warnings

- no private keys in plaintext
- no auto-trade without explicit risk controls
- no copy-trade until monitoring accuracy is proven
